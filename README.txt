2.7: AI選択→次の操作案内の順序修正、ICSのGoogleカレンダー登録手順、旅行条件に応じた持ち物候補（AI回答自動解析なし）を追加。旧プランも読み込み可能。

2.8: 持ち物設定をプランごとに保存し、通常の画面更新ではリセットしない。AI相談条件の既存プラン反映、複数旅行タイプ、国内・海外別提案、子どもの人数の数値解析を修正。

2.9：旅行準備を3ステップ構成に変更。AI相談条件との差分を選択して反映し、自動・手動の持ち物提案を明確に切替。

2.10：AI相談条件の差分確認時に値を固定し、フォーム変更時には確認をやり直す方式へ変更。持ち物の追加件数を実件数で表示。旅行先の区分をプランへ保存・同期し、海外向け候補に反映。

2.11：持ち物設定の保存状態と画面の同期、旅行先区分の優先順位表示、条件変更時の候補無効化、しおり・共有前のプレビューとメモ初期除外を追加。

2.12：印刷用しおりのプレビューを出力HTMLと統一。共有時のプラン内容をスナップショットとして固定。持ち物の国内・海外区分を「旅行条件に合わせる／手動指定」で明確化。個人情報の注意文を拡充。

2.13：新規プラン作成時にAI相談条件を引き継ぎ、既存プランへの予定取り込み時は未設定項目だけ自動補完。既存値の無断上書きを防止。「差分」等の難しい文言を平易化。手動指定の国内・海外区分は保護。

2.14：AI相談反映ボタンで、プラン未作成なら入力内容から新規作成。ボタン付近に操作結果やエラーを表示。

2.15：未設定の旅行条件をワンタップ補完。既存値の変更だけ確認。子ども人数の未設定(null)と0人を区別。重複予定でも不足項目を補完。日付検証を追加。
