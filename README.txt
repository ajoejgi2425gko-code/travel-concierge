# 旅コンシェルジュ PWA

## 公開方法（ConoHa WING / GitHub Pages）
1. ZIPを解凍します。
2. `index.html`、`style.css`、`app.js`、`manifest.webmanifest`、`sw.js`、`icon.svg` を同じフォルダに置きます。
3. ConoHa WINGで公開する場合は、サイトの公開フォルダ内に専用フォルダ（例：`travel/`）を作り、その中へ全ファイルをアップロードします。
4. `https://あなたのドメイン/travel/` にアクセスして動作確認します。
5. HTTPSでアクセスするとPWAとしてインストールできます（ブラウザの対応状況によります）。

## GitHub Pagesで公開する場合
このフォルダ内のファイルをリポジトリの公開対象フォルダにアップロードしてください。HTTPSで公開されれば利用できます。

## 使い方
- 旅行条件を入力・選択して「AIへの相談文を作成する」を押します。
- 「プロンプトをコピー」を押します。
- ChatGPTなどを開いて、入力欄に貼り付けて送信します。
- AIサービス側でWeb検索が利用できる場合は、最新情報の確認に役立ちます。

## 費用・プライバシー
- このアプリ自体は外部AI APIに接続しません。APIキーも不要です。
- 入力内容はサーバーに送信・保存せず、ブラウザ内でプロンプトを生成します。
- AIサービス側の利用条件・料金は、そのサービスの契約やプランに従います。
- Google Fontsを読み込む設定です。完全オフラインで外部通信を避けたい場合は、style.css先頭のGoogle Fontsの`@import`を削除してください。

## 注意
- PWAのオフラインキャッシュはアプリ画面用です。生成したプロンプトを外部AIへ送信するにはインターネット接続が必要です。
- Service Workerの更新が反映されない場合は、ブラウザを再読み込みしてください。
